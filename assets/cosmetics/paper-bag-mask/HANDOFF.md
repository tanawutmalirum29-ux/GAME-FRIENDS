## สีคงที่และลำดับการวาด

ใช้กระดาษครีม/งาช้าง เงาพับสีเทาอุ่น และหมึกดำ ไม่มี `currentColor`, root `color` หรือ color slot ไม่สร้างไฟล์ `colors/` ซ้ำตามสีผู้เล่น ไม่ tint ถุงตาม `player.color`

สีแดงที่เห็นตามภาพอ้างอิงคือสีตัวละครที่มองผ่านช่องเปิด งานนี้ไม่วาดเส้นแดงหรือพื้นแดงติดมากับหน้ากาก ช่องใต้ชายถุงและรอยพับระหว่างแผ่นกระดาษเผยชั้น avatar จริง หากไม่มีตัวละครอยู่ใต้ช่องนั้นจะเห็นพื้นหลังตามธรรมชาติ

ตา X และปากเป็นหมึกทึบ **ไม่ใช่รูเจาะตา** วาดหน้ากากหลังชั้นหัว/ตาเดิมและก่อน label/status effect ห้ามวาดตาเดิมซ้ำบนหน้ากากหรือเปลี่ยนตา X เป็นช่องให้เห็นตาเดิม การถอดหน้ากากกลับไปใช้ avatar เดิมโดยไม่แก้รูปทรงหัว

ใช้ overlay cache ตาม `accessoryId + projection` ร่วมกันทุกสีผู้เล่นได้ ส่วน cache ภาพที่ประกอบตัวละครแล้วต้องคงแยกสี/ท่าของตัวละคร อย่าใช้ตัวอย่างที่ฝังตัวละครสีแดงเป็น overlay

## พิกัดและทิศ

### Portrait

- ฐานตัวละคร `0 0 96 96`, anchor `(48,48)` ขนาดหัวเดิม
- หน้ากาก `viewBox="0 -4 96 104"` เผื่อขอบพับบนและชายถุง
- หลัง translate ไปกลาง portrait ให้ `k = portraitSize / 96` แล้ววาดที่ `(-48*k,-52*k,96*k,104*k)`
- ไม่ย่อภาพที่มี padding กลับลงกรอบ 96 × 96 และไม่ย่อหัวเพื่อใส่ถุง

### Overhead

- `viewBox="0 0 64 64"`, anchor `(32,32)`, head pivot `(32,30)`, forward `(0,-1)`
- หลัง translate/rotate ตามตัวละคร วาดที่ `(-26,-26,52,52)` world units ตามอัตราเดิม `52/64` แล้วคูณ scale เดิมของผู้เรียก
- **ปากและชายถุงหยักหันไปด้านหน้า −Y ส่วนกระดาษพับและร่อง Y อยู่ด้านหลัง +Y** แผงลายหน้าเอียงและย่อความลึกตามกล้อง
- แผงหน้าตาม artwork ใช้ `translate(32 28) rotate(180) scale(.54 .28) translate(-48 -8)` เฉพาะแผงลายหน้า ไม่หมุนทั้งหัวหรือส่วนกระดาษพับ
- ตัวอย่างหมุน +90° ให้หน้าหันขวาตามภาพอ้างอิง ปากกับชายหยักจึงอยู่ขวา ส่วนกระดาษพับอยู่ซ้าย อย่านำหน้า portrait มาย่อโดยไม่จัดทิศ เพราะปากจะกลับเข้าหัว

ลำดับใน asset: รอยพับข้าง → แผ่นกระดาษด้านหลัง → แผงลายหน้าด้านหน้า ช่องรอยพับเป็นช่องว่างระหว่างแผ่นจริง ไม่มีกล่องทึบรองใต้รอยแยก

ระหว่างต่อยให้หน้ากากติดตาม **head transform** และ attackFacing เดียวกับหัวตาม `assets/animations/punch-v2/timing.json`: `translate(torsoDx*.55, torsoDy*.55) rotate(headRotationDeg 32 30)` ไม่ติดกับ torso twist ทั้งก้อน คงขนาดตัวละคร เงาพื้น collision, pickup, bounds และ physics เดิม Padding ไม่ใช่ hitbox ถ้าฝังหลาย SVG inline ใน DOM เดียว ให้ namespace gradient/clip IDs และ `url(#...)` ให้ไม่ชนกัน

## ส่งต่อให้ AI ตัวถัดไป

1. เพิ่ม `paper-bag-mask` ถัดจาก `plumed-turban` ใน cosmetic selection ต่อผู้เล่น รวมไม่ใส่เป็น 8 ตัวเลือก เก็บทั้งเจ็ดชุดและทิศภาพที่แก้ไว้บนบรันช์เดิม
2. เชื่อม B แบบหนึ่งขั้นต่อการกดใหม่เฉพาะในเขต `wardrobe` แสดง “B เปลี่ยนเครื่องแต่งกาย” คง B นอกเขต/ในเกมตามเดิม เก็บการเลือกเมื่อออกจากเขตและใช้ sync/reconnect เดิม
3. ส่ง cosmetic selection ผ่าน state ของ Plaza ไป renderer ให้ครบ portrait, overhead, punch และ fallback วาดหน้ากากหลังตาเดิม ใช้สีคงที่และช่องโปร่งใสตาม SVG
4. อ่าน owner instructions/CI policy แล้วทดสอบทุกสี/ทิศ/ท่า ตาเดิมไม่โผล่บนถุง ปากมุมบนหันไปด้านหน้า ช่องรอยพับไม่ติดสีแดง การถอดกลับเป็นตัวเดิม clipping มือถือ/iPad, B edge, ลำดับ 8 ตัวเลือก, sync และ reconnect
5. เปิด PR ตาม workflow หลังเชื่อมและทำ preflight โดย AI ที่รับผิดชอบ QA รวมเมื่อ required checks ของ latest head ผ่านครบ

รอบภาพนี้สร้างเฉพาะ SVG, metadata, ตัวอย่าง และคำแนะนำส่งต่อ **ไม่ได้รันเกม, browser, build, syntax check, QA, tests หรือ CI และไม่เปิด PR/รวม main** ภาพ SVG/PNG ตัวอย่างเป็นงานประกอบภาพ ไม่ใช่ผลทดสอบเกม
