หมวกสามชุดแรกใช้ **root SVG `color` → `currentColor`** ตั้งค่าสีจาก `player.color` ก่อน decode ภาพ หรือเลือกไฟล์สีสำเร็จรูปใน `colors/` อย่า tint ทั้งภาพ เพราะจะเปลี่ยนผ้าขาว ตัวหมวกดำ ตราขาว และทองของมงกุฎตามไปด้วย ลูกกลมปลายยอดมงกุฎเป็นทอง ไม่ใช่อัญมณีที่เปลี่ยนสี

`shades-white-beard` ใช้สีดำ/ขาว/เทาตายตัว ไม่มี `currentColor` หรือ color slot ใช้ SVG เดียวต่อมุมร่วมกันทุกสีผู้เล่น ไม่ต้องสร้าง variants หรือ tint overlay การเปลี่ยนสีผู้เล่นเปลี่ยนเฉพาะตัวละครเดิม แว่นกับหนวดเคราเป็นชุดเดียวในลำดับ B นี้ ไม่ใช่สองตัวเลือกและไม่ได้ซ้อนเพิ่มบนหมวกอื่นโดยอัตโนมัติ

## ให้ AI ตัวถัดไปดำเนินการ

1. เชื่อมทั้งสี่ ID เข้า cosmetic selection ของผู้เล่นแต่ละคน รวม `none` เป็น 5 ตัวเลือก ให้กด B ได้เฉพาะใน `wardrobe` ของ Plaza และกดค้างเปลี่ยนครั้งเดียว ใช้ข้อความ **“B เปลี่ยนเครื่องแต่งกาย”** ใช้ B นอกเขต/ในเกมตามหน้าที่เดิม เก็บตัวเลือกไว้เมื่อเดินออกจากเขต
2. ให้สีเชือก/ขอบ/อัญมณีเปลี่ยนตามสีผู้เล่น ส่วนแว่นดำและหนวดเคราขาวคงสีเดิม Sync การเลือกตาม identity/room/reconnect เดิม ส่งข้อมูล cosmetic ผ่าน state ที่ Plaza ส่งเข้า renderer ด้วย
3. วาดทั้ง portrait, overhead, punch และ Canvas fallback ตาม source เดียวกัน Cache ตามชุด/มุมและสีสำหรับชุดที่มี tint เท่านั้น แว่นกับหนวดเคราใช้ overlay cache ร่วมกันทุกสี ให้ไอคอน/portrait มีพื้นที่สำหรับปีก ยอด และเคราโดยไม่ลดขนาดหัวหรือแก้ physics
4. อ่าน `AGENTS.md`, `docs/CI_TESTING.md`, กฎ map scale และกฎ connection ล่าสุด แล้วทดสอบภาพจริงทุกสี/ทิศ/ท่า, B ทั้งในและนอกเขต, ลำดับ 5 ตัวเลือก, sync, fallback, clipping ของเครื่องแต่งกายกับ UI และมือถือ/iPad รวมถึงเลนส์ทึบปิดตาเดิมในทุกท่า
5. เปิด PR ตาม workflow หลังเชื่อมและทำ preflight โดย AI ที่รับผิดชอบ QA รวมเมื่อ required checks ของ latest head ผ่านครบเท่านั้น

รอบภาพนี้ไม่ได้รันเกม, browser, build, syntax check, tests หรือ CI และไม่เปิด PR ที่จะเริ่ม QA อัตโนมัติ ไม่มีการปิด CI หรือแก้ชุดทดสอบ ภาพตัวอย่างเป็นการประกอบ SVG เพื่อส่งงาน ไม่ใช่ผลตรวจเกม
