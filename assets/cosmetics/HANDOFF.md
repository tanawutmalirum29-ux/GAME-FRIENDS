# GAME FRIENDS — ชุดหมวกบนบรันช์เดียวกัน

**สาขา: `art/rope-hat-svg-2077-2078` · งาน SVG เท่านั้น · ยังไม่เชื่อมเกม/QA/ทดสอบ/รวม main**

ผู้ใช้ให้เพิ่มหมวกโจรสลัดตามภาพด้านหน้าและด้านบนลง **บรันช์เดิม** ของหมวกผ้าขาวเชือกคู่ สีขอบบนของหมวกโจรสลัดเปลี่ยนตามสีตัวละคร สีดำของหมวกและตรากะโหลกขาวคงเดิม ผู้ใช้ยังห้าม QA และการทดสอบทั้งหมดในรอบทำภาพนี้

## ลำดับกด B ล่าสุด

**ไม่ใส่หมวก → หมวกผ้าขาวเชือกคู่ → หมวกโจรสลัด → ไม่ใส่หมวก**

ใช้รายการใน [wardrobe-assets.json](wardrobe-assets.json) และภาพ [wardrobe-cycle.svg](wardrobe-cycle.svg) เป็นข้อกำหนดส่งต่อ ทั้งสองไฟล์นี้ **ไม่ใช่การลงทะเบียนหรือระบบสลับที่ทำงานแล้ว**

อ่าน [รายละเอียดหมวกผ้าขาว](white-rope-wrap/HANDOFF.md) สำหรับจุดเชื่อม Party Plaza, B edge, sync และ renderer; อ่าน [รายละเอียดหมวกโจรสลัด](pirate-hat/HANDOFF.md) สำหรับ padding และสีขอบ ใช้ชุดใหม่รวมกัน ไม่ทับหรือทิ้งหมวกผ้าขาว

| ID | ภาพตัวอย่าง | ส่วนที่เปลี่ยนตามสีผู้เล่น |
|---|---|---|
| `none` | ตัวละครมาตรฐาน | ไม่วาด overlay |
| `white-rope-wrap` | [สองมุม/12 สี](white-rope-wrap/preview.svg) | เชือกสองวง |
| `pirate-hat` | [สองมุม/12 สี](pirate-hat/preview.svg) | ขอบบนเท่านั้น |

ทั้งสองชุดใช้ **root SVG `color` → `currentColor`** ตั้งค่าสีจาก `player.color` ก่อน decode ภาพ หรือเลือกไฟล์สีสำเร็จรูปใน `colors/` อย่า tint ทั้งภาพ เพราะจะเปลี่ยนผ้าขาว ตัวหมวกดำ และตราขาวตามไปด้วย

## ขนาดภาพแต่ละหมวกต่างกัน แต่ขนาดหัวเท่าเดิม

| หมวก/มุม | viewBox | Anchor | กรอบวาดหลัง translate ไป origin |
|---|---|---|---|
| ผ้าขาว / หน้า | `0 0 96 96` | `(48,48)` | `(-48,-48,96,96) × portraitSize/96` |
| โจรสลัด / หน้า | `-12 -20 120 116` | `(48,48)` | `(-60,-68,120,116) × portraitSize/96` |
| ผ้าขาว / บน | `0 0 64 64` | `(32,32)` | `(-26,-26,52,52)` world units |
| โจรสลัด / บน | `-8 -8 80 80` | `(32,32)` | `(-32.5,-32.5,65,65)` world units |

คูณ scale เดิมของผู้เรียกเพิ่มเติมตาม renderer อย่า fit หมวกทั้งสองชนิดลงกล่องเดียวกันจนหัว/หมวกย่อหรือย้ายศูนย์ พื้นที่โปร่งใสไม่ใช่ hitbox มุม overhead หัน −Y และหมุนตาม heading เดิม ระหว่างต่อย หมวกใช้ head transform ของ punch frame เดียวกับหัว ไม่ใช้ torso twist ทั้งตัว

## ให้ AI ตัวถัดไปดำเนินการ

1. เชื่อมทั้งสอง ID เข้า cosmetic selection ของผู้เล่นแต่ละคน ให้กด B ได้เฉพาะใน `wardrobe` ของ Plaza และกดค้างเปลี่ยนครั้งเดียว ใช้ B นอกเขต/ในเกมตามหน้าที่เดิม เก็บตัวเลือกไว้เมื่อเดินออกจากเขต
2. ให้สีเชือก/ขอบเปลี่ยนตามสีผู้เล่นและ sync การเลือกหมวกตาม identity/room/reconnect เดิม ส่งข้อมูลหมวกผ่าน state ที่ Plaza ส่งเข้า renderer ด้วย
3. วาดทั้ง portrait, overhead, punch และ Canvas fallback ตาม source เดียวกัน Cache ตามหมวก/สี/มุม ให้ไอคอน/portrait มีพื้นที่สำหรับปีกหมวกโดยไม่ลดขนาดหัวหรือแก้ physics
4. อ่าน `AGENTS.md`, `docs/CI_TESTING.md`, กฎ map scale และกฎ connection ล่าสุด แล้วทดสอบภาพจริงทุกสี/ทิศ/ท่า, B ทั้งในและนอกเขต, ลำดับ 3 ตัวเลือก, sync, fallback, clipping ของหมวกกับ UI และมือถือ/iPad
5. เปิด PR ตาม workflow หลังเชื่อมและทำ preflight โดย AI ที่รับผิดชอบ QA รวมเมื่อ required checks ของ latest head ผ่านครบเท่านั้น

รอบภาพนี้ไม่ได้รันเกม, browser, build, syntax check, tests หรือ CI และไม่เปิด PR ที่จะเริ่ม QA อัตโนมัติ ไม่มีการปิด CI หรือแก้ชุดทดสอบ ภาพตัวอย่างเป็นการประกอบ SVG เพื่อส่งงาน ไม่ใช่ผลตรวจเกม
