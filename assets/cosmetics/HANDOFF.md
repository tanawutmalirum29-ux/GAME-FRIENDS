# GAME FRIENDS — เครื่องแต่งกาย SVG บนบรันช์เดียวกัน

**สาขา: `art/rope-hat-svg-2077-2078` · ชุด SVG ยังรอเชื่อมระบบหมวก · ไม่มี QA/ทดสอบ/รวม main**

คำสั่งล่าสุดอนุญาตให้แก้ renderer ของแมพในสาขานี้เพิ่มเติมแล้ว: แยกผู้ขับออกจากภาพเครื่องตัดหญ้า รถ เลื่อน และ UFO ให้ดึงตัวละครกลาง รวมถึงแก้ส่วนหัวที่วาดทับและผู้เล่นผี อ่าน [รายละเอียดโค้ดและงานส่งต่อ AI](../../docs/SHARED_AVATAR_HANDOFF.md) การเปลี่ยนนี้ยังไม่ได้เปิดระบบเลือกหมวก/B/sync และไม่ได้รันการทดสอบใด ๆ

ชุดล่าสุดคือ **หน้ากากถุงกระดาษ** ตามภาพด้านหน้าและด้านบน กระดาษครีม ตากากบาท และรอยยิ้มดำใช้สีคงที่ ชายถุงหยักกับช่องรอยพับเผยสีตัวละครจริงจากชั้นล่าง เพิ่มถัดจากหมวกโพกขนนกบน **บรันช์เดิม** มุมบนปากและชายถุงอยู่ด้านหน้า ส่วนรอยพับอยู่ด้านหลัง รักษาเครื่องแต่งกายก่อนหน้าและทิศที่แก้แล้ว ผู้ใช้ห้าม QA และการทดสอบทั้งหมดในรอบทำภาพนี้

อ่าน [รายละเอียดหน้ากากถุงกระดาษ](paper-bag-mask/HANDOFF.md) สำหรับการปิดตาเดิมด้วยกระดาษทึบ ทิศลายหน้ามุมบน และช่องรอยพับที่เผยตัวละครจริง

หน้ากากถุงกระดาษมุมบนอัปเดตผนังซ้าย/ขวาให้ต่อเนื่องและซ้อนใต้แผงหน้าเพื่อคลุมข้างแก้มทั้งสองด้านแล้ว ร่องพับบาง ๆ กลางหลังคายังโปร่งใส พิกัดวางภาพและขนาดหัวคงเดิม

หมวกผ้าขาว โจรสลัด มงกุฎ ฟาโร และหมวกโพกขนนกใช้ **root SVG `color` → `currentColor`** ตั้งค่าสีจาก `player.color` ก่อน decode ภาพ หรือเลือกไฟล์สีสำเร็จรูปใน `colors/` อย่า tint ทั้งภาพ เพราะจะเปลี่ยนผ้าขาว ตัวหมวกดำ ตราขาว และส่วนทองตามไปด้วย ลูกกลมปลายยอดมงกุฎเป็นทอง ไม่ใช่อัญมณีที่เปลี่ยนสี สำหรับฟาโร แถบทองทั้งหมด แถบหน้าผาก และตรางูต้องคงสีทอง เปลี่ยนเฉพาะลายผ้าระหว่างแถบทอง ส่วนหมวกโพกขนนกเปลี่ยนทั้งขนนกและอัญมณีเป็นสีเดียวกัน แต่ผ้าขาวกับแถบ/ตัวเรือนทองคงเดิม

`shades-white-beard` ใช้สีดำ/ขาว/เทาตายตัว ไม่มี `currentColor` หรือ color slot ใช้ SVG เดียวต่อมุมร่วมกันทุกสีผู้เล่น ไม่ต้องสร้าง variants หรือ tint overlay การเปลี่ยนสีผู้เล่นเปลี่ยนเฉพาะตัวละครเดิม แว่นกับหนวดเคราเป็นชุดเดียวในลำดับ B นี้ ไม่ใช่สองตัวเลือกและไม่ได้ซ้อนเพิ่มบนหมวกอื่นโดยอัตโนมัติ

`paper-bag-mask` ใช้กระดาษครีม/งาช้างและหมึกดำตายตัว ไม่มี `currentColor` หรือ variants ตามสี ใช้ SVG เดียวต่อมุมร่วมกันทุกสีผู้เล่น ตากากบาทและปากเป็นหมึกทึบ ไม่ใช่รูที่ให้ตาเดิมโผล่ ส่วนช่องชายถุงและรอยพับเป็นช่องโปร่งใสจริง ไม่มีสีแดงฝังหรือแผ่นสีตัวละครจำลองใน overlay

## ให้ AI ตัวถัดไปดำเนินการ

1. เชื่อมทั้งเจ็ด ID เข้า cosmetic selection ของผู้เล่นแต่ละคน รวม `none` เป็น 8 ตัวเลือก ให้กด B ได้เฉพาะใน `wardrobe` ของ Plaza และกดค้างเปลี่ยนครั้งเดียว ใช้ข้อความ **“B เปลี่ยนเครื่องแต่งกาย”** ใช้ B นอกเขต/ในเกมตามหน้าที่เดิม เก็บตัวเลือกไว้เมื่อเดินออกจากเขต
2. ให้สีเชือก/ขอบ/อัญมณี/ลายผ้าฟาโร/ขนนกเปลี่ยนตามสีผู้เล่น ส่วนแว่นดำ หนวดเคราขาว และถุงกระดาษคงสีเดิม Sync การเลือกตาม identity/room/reconnect เดิม ส่งข้อมูล cosmetic ผ่าน state ที่ Plaza ส่งเข้า renderer ด้วย
3. วาดทั้ง portrait, overhead, punch และ Canvas fallback ตาม source เดียวกัน Cache ตามชุด/มุมและสีสำหรับชุดที่มี tint เท่านั้น แว่นกับหนวดเคราและถุงกระดาษใช้ overlay cache ร่วมกันทุกสี ให้ไอคอน/portrait มีพื้นที่สำหรับปีก ยอด และเคราโดยไม่ลดขนาดหัวหรือแก้ physics อย่าวาดตาเดิมซ้ำบนหน้ากากถุงกระดาษ ใช้ transform ของตัวกลางรวม `heading`, `local`, `scale`, `alpha` ที่ผู้ขับในแมพส่งเข้ามา ไม่เพิ่มหมวกซ้ำในภาพพาหนะ
4. อ่าน `AGENTS.md`, `docs/CI_TESTING.md`, กฎ map scale และกฎ connection ล่าสุด แล้วทดสอบภาพจริงทุกสี/ทิศ/ท่า, B ทั้งในและนอกเขต, ลำดับ 8 ตัวเลือก, sync, fallback, clipping ของเครื่องแต่งกายกับ UI และมือถือ/iPad รวมถึงเลนส์ทึบ/ถุงกระดาษปิดตาเดิมในทุกท่า ลายทองฟาโรคงเดิมเมื่อเปลี่ยนสี ขนนกมุมบนเอนไปทางท้ายศีรษะ และปากกับชายถุงอยู่ด้านหน้าตัวละคร
5. เปิด PR ตาม workflow หลังเชื่อมและทำ preflight โดย AI ที่รับผิดชอบ QA รวมเมื่อ required checks ของ latest head ผ่านครบเท่านั้น

รอบภาพนี้ไม่ได้รันเกม, browser, build, syntax check, tests หรือ CI และไม่เปิด PR ที่จะเริ่ม QA อัตโนมัติ ไม่มีการปิด CI หรือแก้ชุดทดสอบ ภาพตัวอย่างเป็นการประกอบ SVG เพื่อส่งงาน ไม่ใช่ผลตรวจเกม
