## เปลี่ยนเฉพาะขอบบน

ตั้ง `color` บน root `<svg>` เป็นสีปัจจุบันของผู้เล่นก่อน serialize/decode เป็น `Image` เช่น `color="#f53695"` ส่วน `data-part="upper-trim"` ใช้ `stroke="currentColor"` เฉพาะขอบบนและขอบปีกที่ม้วนขึ้น ส่วนสีดำ/เงาหมวกและกระดูกขาวเป็น neutral คงที่

ไม่ tint ทั้งภาพ ไม่ทำให้กะโหลกหรือผิวหมวกกลายเป็นสีผู้เล่น ไม่อาศัย CSS ของ `<img>` ภายนอกเพื่อเปลี่ยน `currentColor` ใน SVG image เมื่อสีผู้เล่นเปลี่ยนต้องเปลี่ยนสีขอบและ cache key ด้วย

ส่วนที่แยกในภาพ: `black-felt`, `rolled-side-tips`, `front-fold`, `recessed-crown`, `upper-trim`, `skull-and-bones` เฉพาะขอบใช้สีผู้เล่น รอยเย็บ/ไฮไลต์/เงาเป็นสีขาวดำโปร่งใส

## Padding สำหรับปีกกว้าง

### ด้านหน้า

- ฐานตัวละครเดิม `0 0 96 96`, anchor `(48,48)`
- หมวก `viewBox="-12 -20 120 116"` เผื่อปีกซ้ายขวาและยอดหมวกเหนือศีรษะ
- ให้ `k = portraitSize / 96`; หลัง translate ไปกลาง portrait วาด overlay ที่ `(-60*k, -68*k, 120*k, 116*k)`
- วาดตัวละครเดิมด้วยขนาด portrait เดิม ห้ามย่อหัวให้พอดีรูปหมวกที่มี padding
- UI ที่ clip portrait ต้องเผื่อพื้นที่ปีก/ยอดในขั้นเชื่อม ไม่ขยาย hitbox หรือตั้งขนาดหัวใหม่เพื่อหลบ clipping

### ด้านบน

- ฐานตัวละครเดิม `0 0 64 64`, anchor `(32,32)`, pivot หัว `(32,30)`
- หมวก `viewBox="-8 -8 80 80"`, หน้าไป `(0,-1)` ตามเกม
- **ทิศตรากะโหลกมุมบน:** ยอดกะโหลกชี้เข้ามงกุฎหมวก `(0,+1)` ส่วนฟัน/กรามชี้ออกไปทางหน้าตัวละคร `(0,-1)` ใช้ `translate(32 24.5) rotate(180) scale(.5 .32)` เฉพาะกลุ่มตรามุมบน ตราด้านหน้าคงทิศเดิม ห้ามนำตรา portrait มาย่อโดยไม่กลับทิศตามผิวปีกหมวก
- หลัง translate/rotate ตามตัวละคร วาด overlay ที่ `(-32.5,-32.5,65,65)` world units อัตราเดิม `52/64`
- บวก scale ของ renderer ตามเดิม รักษา origin, shadow, collision และขนาดตัวละครปกติ
- ตอนต่อยให้ใช้ transform ของ **หัว** ในเฟรมเดียวกันตาม `assets/animations/punch-v2/timing.json` และ attackFacing ที่ renderer ใช้ ไม่หมุนหมวกด้วย torso twist

วาด overlay หลังหัวและก่อน label/status effect รักษาลำดับซ้อนของแขน/วัตถุถือให้ตรงมุมกล้องในขั้น integration ภาพตัวอย่างไม่ได้ทดสอบ clipping หรือท่าต่อยจริง

## ส่งต่อให้ AI ที่เชื่อมและทดสอบ

เชื่อมหมวกผ้าขาว โจรสลัด มงกุฎ ชุดแว่นดำกับหนวดเคราขาว หมวกฟาโร และหมวกโพกขนนกกับ B ในเขต `wardrobe`, ตรวจ metadata/ข้อความให้เป็น 7 ตัวเลือกรวมไม่ใส่, เก็บการเลือกแยกแต่ละผู้เล่น, sync และจำค่าตามระบบเดิม ตรวจทุกสี/ทุกทิศ/idle-walk-hold-punch/fallback และ portrait/UI มือถือ โดยเฉพาะ padding ของแต่ละชุด

อ่าน owner instructions/CI policy ก่อนรัน QA และเปิด PR รวมเมื่อ required checks ของ latest head ผ่านครบ ภาพชุดนี้ยังไม่มีผลทดสอบหรือคำรับรองว่าเชื่อมเกมแล้ว
