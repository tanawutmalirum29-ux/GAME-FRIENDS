## ลายทองสลับสีตัวละคร

ตั้ง attribute **`color` บน root `<svg>`** ตามสีปัจจุบันของผู้เล่นก่อน decode/serialize เช่น `color="#36d9e5"` หรือ `color="#c62222"` ส่วน `data-part="player-color-stripes"` ใช้ `fill="currentColor"` และโผล่เป็นลายผ้าระหว่างแถบทอง มีแสง/เงาขาวดำโปร่งใสเพื่อเก็บรูปทรงผ้า

ส่วน `gold-stripes`, `gold-side-stripes`, `gold-brow-band` และ `gold-cobra` ใช้ทองคงที่ทั้งหมด รวมถึงกลางกระหม่อม แถบคาดหน้าผาก และตรางู ไม่มีการทำให้ทองเปลี่ยนเป็นสีผู้เล่น ห้าม tint ทั้งภาพหรือเปลี่ยน stop ของ gradient ทองตามสีตัวละคร

การเปลี่ยนสีผู้เล่นไม่เปลี่ยนลำดับหรือจำนวนลาย เปลี่ยนเฉพาะช่องสีที่สลับกับทองทั้งมุมหน้าและมุมบน ไม่อาศัย CSS ของ `<img>` ภายนอกส่งสีเข้า SVG image Cache overlay ตาม `hatId + color + projection` และเปลี่ยน key เมื่อสีผู้เล่นเปลี่ยน โดยไม่ parse SVG ใหม่ทุกเฟรม

มี 24 ไฟล์พร้อมใช้สำหรับสีปัจจุบันใน `src/app/core/runtime.js` ถ้าใช้สีอื่น ให้ตั้ง root color ของ template เดียวกัน ไม่ต้องเพิ่มสีไปที่ตรางูหรือแถบทอง

## พิกัดและทิศ

### Portrait

- ฐานตัวละครเดิม `0 0 96 96`, anchor `(48,48)` ขนาดหัวเดิม
- หมวกใช้ `viewBox="-24 -40 144 144"` เผื่อทรงผ้ากว้างและสูงโดยไม่ย่อหัว
- หลัง translate ไปกลาง portrait ให้ `k = portraitSize / 96` แล้ววาด overlay ที่ `(-72*k,-88*k,144*k,144*k)`
- อย่าย่อภาพที่มี padding ลงเหลือกรอบ 96 × 96 เพราะแถบหน้าผากจะเลื่อนและหมวกผิดสัดส่วน เผื่อพื้นที่ด้านบน/ข้างใน UI ที่ clip ภาพแทน

### Overhead

- ฐานตัวละครเดิม `0 0 64 64`, anchor `(32,32)`, head pivot `(32,30)`
- หมวกใช้ `viewBox="-8 -8 80 80"`, forward `(0,-1)` ช่องใบหน้าและตาอยู่ทาง −Y ส่วนลายผ้าแผ่ไปทางท้ายศีรษะ +Y
- วาดที่ `(-32.5,-32.5,65,65)` world units ตามอัตราเดิม `52/64` หลัง translate/rotate ตามตัวละคร แล้วคูณ scale เดิมของผู้เรียก
- ตรางูอยู่กลางแถบหน้าผาก หันหน้าไป −Y ทรงตั้งถูกย่อความลึกตามมุมกล้อง โดยหัว/แผ่แม่เบี้ยที่ยกสูงฉายไปทางผ้าด้านหลัง ส่วนฐานสั้นอยู่บนแถบด้านหน้า ไม่เอา portrait มาหมุนทั้งใบแทน top SVG
- ตัวอย่างมุมบนขวามือหมุน **−90° ให้หันซ้าย** ตามภาพอ้างอิง ตัว production ยังหันขึ้น −Y ตามมาตรฐานเกม

ลำดับวาด: ผ้าลายคลุมท้ายศีรษะและชายผ้า → แถบทองหน้าผาก → ตรางู วาง overlay หลังหัว/ตาของตัวละครและก่อน label/status effect ระหว่างต่อยต้องติดตาม **head transform** และ attackFacing ของเฟรมเดียวกันตาม `assets/animations/punch-v2/timing.json`: `translate(torsoDx*.55, torsoDy*.55) rotate(headRotationDeg 32 30)` ไม่ใช้ torso twist ทั้งก้อน

ไม่แก้ขนาดหัว collision, bounds, pickup, physics หรือ viewport ตามเงาร่างหมวก พื้นที่ padding ไม่ใช่ hitbox ถ้าฝังหลาย SVG inline ใน DOM เดียว ให้ namespace gradient/clip IDs และ `url(#...)` ให้ไม่ชนกัน

## ส่งต่อ AI ที่เชื่อม ทดสอบ และรวม

1. เพิ่ม `pharaoh-nemes` ถัดจาก `shades-white-beard` ในการเลือกเครื่องแต่งกายต่อผู้เล่น รวม `none` เป็น 8 ตัวเลือก รักษาทิศตรากะโหลกโจรสลัดและรอยเว้าจมูกแว่นมุมบนที่แก้แล้ว
2. เชื่อม B แบบหนึ่งครั้งต่อการกดใหม่ในเขต `wardrobe` เท่านั้น ใช้ข้อความ “B เปลี่ยนเครื่องแต่งกาย” และคงหน้าที่ B เดิมนอกเขต/ในเกม เก็บตัวเลือกเมื่อเดินออกจากเขต
3. ส่ง cosmetic selection ผ่าน state ของ Plaza ไป renderer และ sync/reconnect ตาม identity/room เดิม ห้ามเก็บการเลือกเป็นค่ากลางที่เปลี่ยนหมวกทุกคน
4. เชื่อม portrait, overhead, punch และ fallback โดยใช้กรอบวาดของแต่ละชุด ให้เฉพาะลายผ้าฟาโรตามสีผู้เล่น ส่วนทองและชุดแว่นหนวดเคราคงสีเดิม
5. อ่าน owner instructions/CI policy แล้วทดสอบทุกสี/ทิศ/ท่า ลายสลับและทองคงที่เมื่อเปลี่ยนสี ใบหน้าเปิด/ทิศหมวก clipping มือถือ/iPad, B edge, ลำดับ 8 ตัวเลือก, sync และ reconnect จากนั้นเปิด PR ตาม workflow และรวมเมื่อ required checks ของ latest head ผ่านครบ

รอบนี้สร้างเฉพาะ SVG, metadata, ภาพตัวอย่าง และคำแนะนำส่งต่อ **ไม่ได้รันเกม, browser, build, syntax check, QA, tests หรือ CI และไม่เปิด PR/รวม main** ภาพ SVG/PNG ตัวอย่างไม่ใช่ผลทดสอบเกม
