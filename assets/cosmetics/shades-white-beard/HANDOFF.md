ผู้ใช้ให้เพิ่มแว่นดำพร้อมหนวดและเคราขาวตามภาพด้านหน้าและ overhead โดย **ไม่ต้องมีส่วนเปลี่ยนสีตามตัวละคร** เพิ่มในสาขา `art/rope-hat-svg-2077-2078` เดิม และห้าม QA หรือทดสอบในรอบทำ SVG

อ่าน [HANDOFF รวม](../HANDOFF.md) และ [wardrobe-assets.json](../wardrobe-assets.json) สำหรับลำดับ B ล่าสุด: `none → white-rope-wrap → pirate-hat → golden-crown → shades-white-beard → none` ชุดแว่นกับหนวดเคราเป็นหนึ่งตัวเลือก รวมทั้งหมด 5 ตัวเลือก ไม่แยกเป็นแว่น/หนวดคนละรายการและไม่ซ้อนหมวกอื่นโดยอัตโนมัติ

## ทุกส่วนใช้สีคงที่

แว่นและขาแว่นใช้ดำ/เทาถ่าน ส่วนหนวด จอน และเคราใช้ขาวกับเงาเทากลาง ไม่มี `currentColor`, root `color`, CSS color variable หรือช่องที่ต้องผูกกับ `player.color` ไม่สร้าง `colors/` ซ้ำ 12 ชุด และไม่ tint ภาพเมื่อผู้เล่นเปลี่ยนสี

ใช้ SVG เดียวต่อมุมร่วมกันได้ทุกสีผู้เล่น Cache overlay ตาม `accessoryId + projection` ส่วน cache ภาพตัวละครที่ประกอบเสร็จแล้วยังคงต้องแยกตามสี/ท่าของตัวละคร ห้ามนำตัวอย่างสีเหลืองมาใช้แทน overlay

ชิ้นหลักมี `data-part` สำหรับ `sunglasses`, `moustache`, `beard`, `sideburns` และ `glasses-temples` ตามมุมที่มีชิ้นนั้น เลนส์เป็นพื้นทึบให้ปิดตาเดิม วาดเครา/จอนก่อน หนวดถัดมา และแว่นชั้นหน้าเพื่อให้หนวดสอดใต้แว่น ไฮไลต์เลนส์เป็นสีคงที่ ไม่ใช่การเจาะช่องให้เห็นตา

## พิกัดและทิศ

### Portrait

- ตัวละครเดิมใช้กรอบ `0 0 96 96`, anchor `(48,48)` โดยไม่ย่อหัว
- เครื่องแต่งกายใช้ `viewBox="0 0 96 116"` เพิ่มพื้นที่ใต้คางสำหรับปลายเครา
- หลัง translate ไปกลาง portrait ให้ `k = portraitSize / 96` แล้ววาด overlay ที่ `(-48*k,-48*k,96*k,116*k)`
- ไม่ใช้ความสูง 116 เป็นฐานย่อภาพกลับลง 96 เพราะจะเลื่อนแว่นและย่อใบหน้า เผื่อพื้นที่ใต้คางใน UI ที่ clip ภาพแทน

### Overhead

- ตัวละครเดิมใช้กรอบ `0 0 64 64`, anchor `(32,32)`, head pivot `(32,30)`
- เครื่องแต่งกายใช้ `viewBox="-8 -16 80 80"`, forward `(0,-1)` เคราต้องอยู่ด้านหน้าทิศ −Y และขาแว่นทอดไปด้านข้าง/หลัง
- **ทิศแว่นมุมบนแก้แล้ว:** รอยเว้าสันจมูกและส่วนโค้งล่างของเลนส์หันออกไปทางหนวด/เครา −Y ขอบคิ้วต่อเนื่องอยู่ด้านหน้าผาก +Y ขาแว่นยังทอดไปด้านหลัง +Y อย่ากลับทั้ง overlay เพราะจะทำให้เคราและขาแว่นผิดทิศ
- หลัง translate/rotate ตามตัวละคร วาด overlay ที่ `(-32.5,-39,65,65)` world units ตามอัตราเดิม `52/64` แล้วคูณ scale เดิมของผู้เรียก
- กรอบนี้มี padding ไม่สมมาตรรอบหัว อย่าใช้ `(-32.5,-32.5,65,65)` แบบโจรสลัด เพราะจะทำให้แว่นและเคราเลื่อนลง
- ตัวอย่างขวามือใน `preview.svg` หมุน **+90° ให้หันขวา** ตามภาพ overhead ที่ผู้ใช้ส่ง เคราอยู่ทางด้านขวาของภาพนั้น ตัว production ยังหัน −Y ตามมาตรฐานเกม

วาด overlay หลังหัว/ตาและก่อน label/status effect คงลำดับแขนหรือวัตถุถือให้เหมาะกับมุมกล้องในขั้น integration ระหว่างต่อยใช้ **head transform** และ attackFacing เดียวกับหัวตาม `assets/animations/punch-v2/timing.json`: `translate(torsoDx*.55, torsoDy*.55) rotate(headRotationDeg 32 30)` ไม่ติดเครากับ torso twist ทั้งตัว

ไม่ขยาย collision, bounds, pickup หรือ hitbox ตามปลายเครา ไม่เปลี่ยนขนาดหัว/แขน เงาพื้น หรือ viewport เพื่อให้พอดี overlay ถ้าฝังหลาย SVG inline ใน DOM เดียว ให้ namespace gradient IDs และ `url(#...)` ให้ไม่ชนกัน

## ส่งต่อ AI ที่เชื่อมและทดสอบ

1. เพิ่ม `shades-white-beard` ถัดจาก `golden-crown` ใน cosmetic selection ของผู้เล่นแต่ละคน ใช้ลำดับ 5 ตัวเลือกใน catalog ร่วมกับสามหมวกเดิม รักษาทิศตรากะโหลกมุมบนของโจรสลัดที่แก้ไว้แล้ว
2. ในเขต `wardrobe` ให้ B เปลี่ยนหนึ่งขั้นต่อการกดใหม่ แสดง “B เปลี่ยนเครื่องแต่งกาย” คงหน้าที่ B เดิมนอกเขตและในมินิเกม เก็บตัวเลือกเมื่อเดินออกจากเขตและ sync/reconnect ตามระบบเดิม
3. ส่ง cosmetic selection ผ่าน state ของ Plaza ไป renderer ด้วย ใช้สีคงที่สำหรับชุดนี้และให้ tint เฉพาะส่วนที่ระบุของหมวกสามชุดก่อนหน้า
4. เชื่อม portrait, overhead, punch และ fallback แล้วทดสอบทุกสี/ทิศ/ท่า การปิดตาเดิมด้วยเลนส์ทึบ เคราหันไปด้านหน้า ไม่มีส่วนสีผู้เล่นติดมาใน overlay, clipping, มือถือ/iPad, B edge, sync และ reconnect
5. อ่าน owner instructions/CI policy ก่อนเริ่ม QA และเปิด PR ตาม workflow รวมเมื่อ required checks ของ latest head ผ่านครบ

รอบนี้ทำเฉพาะ SVG, metadata, ภาพตัวอย่าง และคำแนะนำส่งต่อ **ไม่ได้รันเกม, browser, build, syntax check, QA, tests หรือ CI และไม่เปิด PR/รวม main** ภาพตัวอย่าง SVG/PNG เป็นงานประกอบภาพเพื่อส่งมอบ ไม่ใช่หลักฐานทดสอบเกม
