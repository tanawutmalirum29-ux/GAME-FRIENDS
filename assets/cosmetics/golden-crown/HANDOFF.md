## เฉพาะอัญมณีที่เปลี่ยนสี

ตั้ง `color` บน root `<svg>` เป็น `player.color` ก่อน decode/serialize ภาพ เช่น `color="#c62222"` รูปทรงอัญมณีใน `data-part="front-gemstone"` ใช้ `fill="currentColor"` พร้อมเงา/ไฮไลต์ขาวดำโปร่งใส ส่วนตัวเรือนอัญมณี `gem-bezel` และยอดกลม `gold-tip` เป็นสีทองคงที่

ห้าม tint ทั้งมงกุฎ และห้ามเปลี่ยนลูกกลมทุกยอดเป็นสีผู้เล่น อย่าอาศัย CSS ของ `<img>` ภายนอกเพื่อส่งสีเข้า SVG image เมื่อผู้เล่นเปลี่ยนสีให้ปรับ root color หรือเลือก variant ใหม่และเปลี่ยน cache key

อัญมณีด้านหน้าเป็นวงกลมจริง ศูนย์ `(48,29.5)` รัศมี `4.2` ส่วนมุมบนเห็นด้านข้างของอัญมณี จึงฉายเป็นวงรีเล็กที่ `(32,20.85)` รัศมี `(2.35,1.25)` บนแถบหน้ามงกุฎ **อยู่ใกล้หน้าตัวละคร/แนวดวงตา −Y ไม่อยู่ท้ายมงกุฎ**

## พิกัด

### Portrait

- ฐานตัวละครเดิม `0 0 96 96`, anchor `(48,48)`
- มงกุฎ `viewBox="0 -20 96 116"` เพิ่ม padding ด้านบนสำหรับยอด
- หลัง translate ไปกลาง portrait ให้ `k = portraitSize / 96` แล้ววาด overlay ที่ `(-48*k,-68*k,96*k,116*k)`
- คงขนาดหัวเดิม และเผื่อพื้นที่ยอดมงกุฎใน UI ที่มี clipping โดยไม่ย่อหัวหรือแก้ physics

### Overhead

- `viewBox="0 0 64 64"`, anchor `(32,32)`, head pivot `(32,30)`, forward `(0,-1)`
- อัตราเดิม `52/64`, กรอบวาด `(-26,-26,52,52)` world units หลัง translate/rotate ตามตัวละคร แล้วคูณ scale เดิมของผู้เรียก
- ลำดับใน asset: ซี่หลัง → ซี่หน้า → แถบหน้า → อัญมณี เพื่อให้เป็นวงเปิดและซ้อนตามความลึก
- เมื่อต่อย ใช้ head transform และ attackFacing เดียวกับหัวในเฟรม ไม่หมุนด้วย torso twist และไม่แก้ทิศกะโหลกของ asset โจรสลัด

วางหลังชั้นหัวและก่อนป้ายชื่อ/สถานะ คงเงาที่ origin เดิม ไม่ขยาย collision, bounds หรือ hitbox ให้รวมยอดมงกุฎ เผื่อ geometry ตาม metadata ของแต่ละหมวก ไม่ใช้ padded image size ของโจรสลัดมาแทนทุกชุด

## งานของ AI ตัวถัดไป

เชื่อม `golden-crown` เป็นตัวเลือกที่สี่รวม `none` ตามด้วย `shades-white-beard` เป็นตัวเลือกที่ห้า และ `pharaoh-nemes` เป็นตัวเลือกที่หก ในเขต wardrobe กด B หนึ่งครั้งเปลี่ยนหนึ่งขั้น เก็บการเลือกต่อผู้เล่นเมื่อออกจากเขต ใช้ระบบ sync/reconnect เดิม ให้สีอัญมณีตามสีผู้เล่น และคง B ของเขตอื่น/มินิเกมตามเดิม

อ่านกฎ repository/CI ก่อนเชื่อมและทดสอบทุกมุม ทุกสี ทุกท่า idle/walk/hold/punch, fallback, portrait clipping, mobile/iPad, B edge, ลำดับ 6 ตัวเลือก และการ sync แล้วเปิด PR/รวมเมื่อ required checks ของ latest head ผ่านครบ

**รอบนี้สร้างเฉพาะ SVG, metadata และคำแนะนำส่งต่อ ไม่มีการรันเกม, browser, build, syntax check, QA, tests หรือ CI และยังไม่เปิด PR/รวม main**
