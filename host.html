GAME FRIENDS — จอหลัก

หน้านี้สำหรับติดตั้ง จอหลัก (HOST) ไม่ใช่จอยของผู้เล่น

เปิดจอหลัก / สร้างห้อง
เพิ่มจอหลักลงหน้าจอโฮมบน iPad
  1. เปิดหน้านี้ (/host.html) ใน Safari และอยู่ที่หน้านี้ไว้
  2. กด แชร์ → เพิ่มไปยังหน้าจอโฮม
  3. เปิด Open as Web App แล้วกดเพิ่ม
  4. เปิดไอคอน GF HOST ที่เพิ่มใหม่ ระบบจะพาเข้าจอสร้างห้องทันที
จอหลักและจอยใช้ไอคอนคนละรายการ เมื่อเปิดผ่านไอคอน GF HOST จะไม่เริ่มที่หน้าเข้ารหัสจอย
